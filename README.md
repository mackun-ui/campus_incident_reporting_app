# Campus Incident Reporting App

A Flutter mobile app where students report campus issues (water, electricity, facilities, safety, sanitation) and track them until they are resolved. Staff review all reports and update their status.

## Features

- Register and log in with an ALU email (email verification required)
- Submit a report with category, title, description, location, and an optional photo
- Search and filter reports by status and category
- Report details with a status timeline (Submitted, In Progress, Resolved)
- Dashboard with summary counts
- Two roles: **student** (own reports) and **staff** (all reports, can update status)

## Tech stack

- Flutter and Dart
- Provider (state management)
- Firebase Authentication and Cloud Firestore
- Cloudinary (photo storage)

## Run it locally

### 1. Requirements

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Android Studio with an Android emulator (or a physical Android phone)
- A Firebase project with **Authentication (Email/Password)** and **Cloud Firestore** enabled
- A Cloudinary account with an **unsigned upload preset**

### 2. Get the code and install packages

Run these in the folder that contains `pubspec.yaml`:

```bash
git clone https://github.com/mackun-ui/campus_incident_reporting_app.git
cd campus_incident_reporting_app
flutter pub get
```

### 3. Connect Firebase

If `lib/firebase_options.dart` is missing, or you want to use your own Firebase project:

```bash
npm install -g firebase-tools
firebase login
dart pub global activate flutterfire_cli
flutterfire configure
```

Select your Firebase project and choose **Android**. On Windows, if `flutterfire` is not found, use:

```bash
dart pub global run flutterfire_cli:flutterfire configure
```

Then copy the content of `firestore.rules` into **Firebase Console > Firestore Database > Rules** and click **Publish**.

### 4. Set up Cloudinary

The project already has the author's Cloudinary cloud name and upload preset in `lib/core/constants/app_constants.dart`, so photo uploads work without changes. To use your own Cloudinary account, create an unsigned upload preset and replace these values:

```dart
static const cloudinaryCloudName = 'YOUR_CLOUD_NAME';
static const cloudinaryUploadPreset = 'YOUR_UPLOAD_PRESET';
```

### 5. Run the app

Start an emulator, then:

```bash
flutter devices
flutter run
```

## Creating a staff account

Every new account is a student. To make a staff account:

1. Register a new account in the app and verify its email.
2. In **Firebase Console -> Firestore Database -> users**, open that user's document.
3. Change the `role` field from `student` to `staff`.
4. Log out and log in again.

## Notes

- Only ALU emails (`alustudent.com`, `alueducation.com`) can register. These are set in `app_constants.dart`.
- Photos are stored in Cloudinary instead of Firebase Storage, because Firebase Storage needs a paid plan.
